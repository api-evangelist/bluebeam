# Bluebeam

Bluebeam develops smart, simple project efficiency and collaboration software for design and construction professionals worldwide. The Bluebeam Studio API and Studio Prime Integration API provide programmatic access to PDF markup, document collaboration, and construction project management workflows via OAuth 2.0 REST APIs.

**URL:** [View APIs.yml](https://raw.githubusercontent.com/api-evangelist/bluebeam/refs/heads/main/apis.yml)

## APIs

### Bluebeam Studio API
Programmatic access to Studio Sessions for document collaboration, markup management, and PDF review workflows. Create and manage studio sessions, retrieve markup data, and integrate document annotations into AEC construction workflows via OAuth 2.0.

### Bluebeam Studio Prime Integration API
Third-party application integrations with Studio Prime supporting project drawing sets, session management, and markup synchronization for construction project management platforms.
